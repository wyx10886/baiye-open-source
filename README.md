## 本地协作记忆 · Local Collaboration Memory

**Skill / 技能版本：1.1.0** · **Runtime baseline / 运行源码基线：1.7.2** · **2026-11-19** · MIT

一个支持有来源记忆、项目接续、修订纠错及候选隔离的本地协作系统。新版增加可选习惯候选学习、主动消息准备门禁和安全会话编号回收；全新安装默认关闭这些可选能力，不附带个人记忆、账户配置、真实会话或私人日程。

A local collaboration system with provenance-aware memory, project handoffs, traceable corrections and candidate separation. This release adds opt-in habit candidates, proactive preparation gates and safe session-code recycling. Fresh installations keep optional collection and automation features off and include no personal memories, account settings, real sessions or private schedules.
